# Day 39 – PDF Splitter & Merger

## 🚀 Overview

Today I built a **browser-based PDF Splitter & Merger** using Claude. The application is a complete offline productivity tool that enables users to split and merge PDF documents directly in the browser without uploading files to any server.

This project demonstrates how AI can generate commercial-quality software with a modern interface, intuitive workflows, and secure client-side processing.

---

## ✨ Features

* 📄 Split PDF documents into separate pages or custom page ranges
* 📚 Merge multiple PDF files into a single document
* 🖱️ Drag-and-drop file upload interface
* 👀 PDF preview before processing
* 💾 Download processed PDF files instantly
* 🔒 100% client-side processing for privacy
* 🌐 Works completely offline
* 🎨 Modern, responsive UI with smooth interactions

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* Vanilla JavaScript
* PDF processing libraries
* Browser File API
* Drag & Drop API
