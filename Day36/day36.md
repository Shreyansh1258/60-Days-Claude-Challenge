# Day 36 – Cognitive Pattern Explorer

## Overview

Today, I built and explored an interactive **Cognitive Pattern Explorer** using Claude. The application is designed as an educational self-reflection experience that helps users understand different thinking styles through practical scenarios and interactive activities. Instead of acting as a psychological assessment, it encourages reflection on how people approach everyday decisions in different situations.

The application was generated as a complete HTML file and can be opened directly in any modern web browser without requiring additional dependencies.

---

## Objectives

* Explore different approaches to decision-making.
* Reflect on personal thinking tendencies.
* Learn through interactive scenarios and activities.
* Experience how context can influence thinking patterns.
* Generate a fully functional HTML educational application using Claude.

---

## Features

### 🧠 Thinking Styles

The application introduces different ways people naturally process information and make decisions. It focuses on recognizing tendencies rather than assigning fixed labels.

### 🌿 Calm Mode & Stress Mode

Users can experience the activities under two different contexts:

* **Calm Mode** simulates thoughtful decision-making in relaxed situations.
* **Stress Mode** presents similar experiences where pressure may influence choices.

This comparison highlights how context can affect reasoning and priorities.

### 📖 Scenario-Based Learning

Instead of traditional questionnaires, users respond to everyday situations that encourage self-reflection.

Examples include:

* Choosing between multiple priorities
* Solving common problems
* Responding to changing circumstances
* Evaluating different options

### 🎯 Interactive Activities

The application includes engaging exercises such as:

* Drag-and-drop categorization
* Organizing thinking sequences
* Decision-making scenarios
* Reflection-based interactions

### 📓 Reflection Journal

After completing all chapters, the application generates a personalized Reflection Journal summarizing the user's responses and overall thinking tendencies.
